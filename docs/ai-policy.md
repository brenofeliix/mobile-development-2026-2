# Artificial Intelligence Usage Policy

The use of Artificial Intelligence tools is allowed and encouraged
when appropriate during course activities.

Examples include:

- ChatGPT;
- Gemini;
- GitHub Copilot;
- Claude;
- other AI-assisted development tools.

## Student Responsibility

The use of AI does not transfer responsibility for the software to the
tool.

Students remain responsible for the correctness, quality, and
understanding of all submitted artifacts.

Students must be able to:

1. Explain the submitted code.
2. Identify how AI was used.
3. Explain what was generated or suggested by AI.
4. Describe what was manually reviewed or modified.
5. Test the application.
6. Validate the implementation against the specification.
7. Identify and correct problems in AI-generated solutions.

## Assessment

Any submitted code may be used during individual questioning.

Students may be asked to:

- explain a function;
- identify where a requirement was implemented;
- modify an existing behavior;
- locate a bug;
- explain a technical decision;
- relate code to an acceptance criterion.

## Core Principle

**AI may generate. The student must understand, validate, and explain.**
