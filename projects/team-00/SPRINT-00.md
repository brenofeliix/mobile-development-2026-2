# SPRINT 00 — Development Environment

## Goal

Prepare the development environment required for Android application
development and become familiar with the Git/GitHub workflow used
throughout the course.

## Sprint Goal

By the end of this Sprint, each team should have an environment capable
of creating, building, and running an Android application.

## Activities

### 1. Team Setup

Define the team members and their GitHub usernames.

### 2. Git and GitHub

Each team must:

- configure Git;
- fork the course repository;
- create a branch for the Sprint;
- create the team's project folder;
- create at least one commit;
- push the branch;
- submit a Pull Request.

### 3. Android Development Environment

Install and configure:

- Android Studio;
- Android SDK;
- Android Emulator.

A physical Android device may also be used when appropriate.

### 4. First Android Application

Create a new Android application using:

- Kotlin;
- Jetpack Compose;
- Android Studio.

Build and run the application using an Android Emulator or physical
device.

## Acceptance Criteria

- AC-01 — Team members are identified.
- AC-02 — Git is correctly configured.
- AC-03 — The course repository has been forked.
- AC-04 — A Sprint branch has been created.
- AC-05 — Android Studio is installed.
- AC-06 — Android SDK is configured.
- AC-07 — An Android Emulator or physical device is available.
- AC-08 — An Android application builds successfully.
- AC-09 — The application runs without crashing.
- AC-10 — At least one commit has been created.
- AC-11 — A Pull Request has been submitted.

## Submission

Create:

`projects/team-XX/SPRINT-00.md`

The file must contain:

- team number;
- team members;
- GitHub usernames;
- development environment status;
- difficulties encountered;
- evidence that the Android application was successfully executed.

## Suggested Branch Name

`team-XX/sprint-00`

Example:

`team-03/sprint-00`

## Suggested Commit Message

`docs: submit sprint 00 team XX`

Example:

`docs: submit sprint 00 team 03`

## Pull Request Title

`[Sprint 00] Team XX — Development Environment`

Example:

`[Sprint 00] Team 03 — Development Environment`
