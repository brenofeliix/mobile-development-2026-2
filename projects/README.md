# Student Projects

Each team must work exclusively inside its assigned directory.

Example:

```text
projects/
├── team-01/
├── team-02/
├── team-03/
└── team-04/
```
A team must not modify files belonging to another team.

## Submission Workflow

All submissions must follow this workflow:

```text
Course Repository
        ↓
       Fork
        ↓
  Sprint Branch
        ↓
     Changes
        ↓
      Commit
        ↓
       Push
        ↓
  Pull Request
        ↓
Instructor Review
        ↓
       Merge
```
## Directory Naming

Use:

`team-XX`

Examples:

- `team-01`
- `team-02`
- `team-03`

## Important Rule

Do not commit directly to the `main` branch of the course repository.

All student submissions must be made through Pull Requests.
