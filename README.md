# Mobile Software Development

## 2026/2

Official repository for the Mobile Software Development course.

Throughout the semester, students will design and develop Android
applications using Kotlin, Android Studio, Git/GitHub, and AI-assisted
development tools.

## Development Workflow

**SPEC → BUILD → VALIDATE → EXPLAIN → COMMIT**

## Workflow

1. Understand the problem.
2. Create or review the specification.
3. Develop the solution.
4. Use documentation and AI tools when appropriate.
5. Build and run the application.
6. Validate the acceptance criteria.
7. Explain the implemented solution.
8. Commit the changes.
9. Submit a Pull Request.

## Artificial Intelligence

The use of AI tools is allowed.

However, students remain responsible for:

- understanding the submitted code;
- testing the solution;
- identifying and fixing errors;
- validating the acceptance criteria;
- explaining the implementation.

Any submitted code may be discussed individually during assessments.

## Course Organization

Activities are organized into Sprints.

- Sprint instructions: `sprints/`
- Specification template: `templates/`
- Student projects and submissions: `projects/`
- Course methodology and policies: `docs/`
